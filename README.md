# SlopCord

Легкий голосовий чат для друзів під Windows (Tauri 2 + React + TypeScript, голос через LiveKit Cloud).

Зараз це **етап 0**: прототип, у якому двоє (або до 10) людей заходять у кімнату й чують одне одного.
Вхід, сервери друзів і текстовий чат будуть на етапі 1 разом із Supabase.

## Що вміє прототип

- Зайти в кімнату за назвою й говорити.
- Голосова активація за замовчуванням: мікрофон передає звук лише тоді, коли ти говориш. Чутливість регулюється повзунком.
- Вимкнути мікрофон, вимкнути звук (тоді сервер узагалі перестає надсилати тобі звук).
- Список учасників і зелене коло навколо того, хто говорить.
- Вибір мікрофона й навушників.
- Автоматичне перепідключення, якщо інтернет на секунду зник.
- Інтерфейс українською та англійською.

## Як запустити (без програмування)

### 1. Ключ LiveKit (один раз)

1. Зайди в [LiveKit Cloud](https://cloud.livekit.io), відкрий свій проєкт → **Settings**.
2. Увімкни **Development token server**.
3. Скопіюй **Token server ID**, що з'явиться під перемикачем.

Цей ID вставляєш у застосунок. Другові дай той самий ID, щоб ви потрапили в один проєкт.
API Secret з LiveKit нікуди копіювати не треба.

> Development token server — тимчасове рішення для тестів: будь-хто з цим ID може зайти в кімнату.
> Тому не публікуй ID відкрито. На етапі 1 токени видаватиме Supabase і лише тим, хто увійшов.

### 2. Інсталятор

1. Відкрий вкладку **Actions** у репозиторії → останній успішний запуск **Build Windows app**.
2. Унизу, в розділі **Artifacts**, завантаж `SlopCord-windows-installer` і розпакуй zip.
3. Запусти `SlopCord_..._x64-setup.exe`. Windows може показати синє вікно SmartScreen: **Докладніше → Виконати все одно** (підпис коду платний, поки відкладаємо).

### 3. Перевірка вдвох

1. Обидва вводите своє імʼя, однакову назву кімнати й той самий Token server ID.
2. Натискаєте **Зайти в кімнату** і дозволяєте доступ до мікрофона.
3. Говорите. Якщо тебе обрізає, тягни повзунок чутливості вліво; якщо друг чує клавіатуру чи вентилятор, тягни вправо.

## Для розробки

Потрібні Node.js 22+, Rust і [залежності Tauri для Windows](https://v2.tauri.app/start/prerequisites/).

```bash
npm install
npm run tauri dev     # запуск із гарячим перезавантаженням
npm run tauri build   # інсталятор у src-tauri/target/release/bundle/nsis
```

## Як влаштовано

| Файл | Що робить |
| --- | --- |
| `src/voice.ts` | Підключення до LiveKit, учасники, мікрофон, звук, перепідключення |
| `src/voiceGate.ts`, `public/voice-gate.worklet.js` | Голосова активація. Працює в аудіопотоці, тож не залежить від того, згорнуте вікно чи ні |
| `src/App.tsx` | Увесь інтерфейс |
| `src/i18n.ts` | Тексти українською та англійською |
| `src-tauri/` | Оболонка Tauri (Rust) |

Оптимізація: Opus моно з DTX (коли мовчиш, майже нічого не надсилається), шумозаглушення й ехоподавлення вбудовані в WebView2, жодних таймерів у фоні, релізна збірка Rust із LTO, без важких UI-бібліотек.
